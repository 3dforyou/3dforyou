# NOVA Store — gratis webshop

Deze webshop is volledig statisch en kan gratis online worden gezet.

## Bestanden
- `index.html` — pagina
- `style.css` — design
- `script.js` — producten en winkelmandje

## Producten aanpassen
Open `script.js` en pas de `products`-lijst aan. Je kunt naam, prijs, emoji en omschrijving veranderen.

## Gratis online zetten
1. Maak gratis een GitHub-account.
2. Maak een nieuwe repository, bijvoorbeeld `mijn-webshop`.
3. Upload `index.html`, `style.css` en `script.js`.
4. Ga naar Settings → Pages.
5. Kies de branch `main` en de map `/ (root)`.
6. Sla op. GitHub geeft je daarna een gratis `.github.io`-adres.

## Belangrijk
Deze versie heeft een werkend winkelmandje, maar nog geen echte betaalfunctie, orderverwerking of verzending. Voor echte betalingen moet een betaalprovider worden gekoppeld. Controleer ook de Nederlandse regels voor online verkoop voordat je live gaat.
